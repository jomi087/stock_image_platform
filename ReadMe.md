# Stock Image Platform (SIP)

## 📌 Overview
This is a **Full Stack Mini Project** built to give an **overall, broad idea of how an  Stock Image Platform looks and works**.

---

## 🏗 Tech Stack

### Frontend
- **React**
- **TypeScript**

### Backend
- **Express**
- **TypeScript**
- **Repository Architecture**
    - Service Layer
    - DI & DIP
    
### Database
- **MongoDB**
---

## 🌐 Deployed URLs
- **Frontend (Live):** [https://](https://stock-image-platform-xi.vercel.app/)
---

## 🎯 Purpose of This Project
This mini project is intended for:
- Learning full-stack application structure
- Understanding backend architecture patterns
- Getting hands-on experience with 
  - React
  - TypeScript
  - MongoDB
  - Understanding how an SIP is designed and implemented
---

    - Stock_Image_Platform\sip_backend

Each sub-directory has its **own `README.md` file**, which explains:
- How to install dependencies
- env setup
- How to run the application
